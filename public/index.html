Administrator setup
Add secrets in Cloudflare Workers → AppForgeAI → Settings → Variables and Secrets. Use names such as GROQ_API_KEY_1 through GROQ_API_KEY_9 or GEMINI_API_KEY_1 through GEMINI_API_KEY_9. The Worker tries configured keys one at a time if a request fails.
